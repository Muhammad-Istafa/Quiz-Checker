## 1. Complete 5-Notebook Pipeline Execution Order

```
[NB0: Audit] ──> [NB1: Data Gen (CPU)] ──> [NB1B: Local 14B Teacher (GPU)]
                                                          │
                                                          ▼
[NB3: Eval Dev/Test] <── [NB2: SFT Train Arms A1/A2 (GPU)]
         │
         ▼ (Gated: Only if A2 beats A1 on dev & false penalties remain high)
[NB2B: NCA Preference Stage] ──> [NB3: Arm A3 Re-Eval]
```

### Step 0: Preflight Audit (`n0_audit.ipynb`)
- **Settings:** CPU, Internet OFF.
- Verifies dataset integrity, schema v3.1 compliance, and cross-split disjointness.

### Step 1: NB1 Data Generation (`nb1_data.ipynb` or CLI)
- **Settings:** CPU, `g++` available (standard Kaggle environment).
- Generates multi-template synthetic training data with syntax-error immunity mutations (void main, missing include, dropped semicolons, Urdu identifiers, misspelled variables) and approach-agnostic references.
- Output: `/kaggle/working/cpp-grader-data-v2/`.

### Step 2: NB1B Local Teacher Distillation (`nb1b_teacher.ipynb`)
- **Settings:** **GPU T4 × 2**, **Internet ON** (to download open-weights teacher).
- Teacher model: `Qwen/Qwen2.5-Coder-14B-Instruct` (or `Qwen/Qwen3-14B`) in 4-bit NF4 with `enable_thinking=False`.
- Zero external APIs: 100% open-weights local execution on Kaggle.
- Uses Ground-Truth Anchored prompting to generate verified 3-step structured traces (Reasoning -> Schema JSON -> Constructive Feedback).
- Includes deterministic fallback to `trace_builder` traces if any teacher generation fails validation.
- Output: `/kaggle/working/output/teacher_distilled/train_sft_distilled.jsonl`.

### Step 3: NB2 SFT Training (`nb2_train.ipynb`)
- **Settings:** **GPU T4 × 2**, **Internet ON**.
- Trains student model `Qwen/Qwen3-4B` in 4-bit NF4 with completion-only masking.
- Run Arms A1 and A2 first (per Round 3 spec):
  - **Arm A1 (Direct JSON Target):** `CFG.train_target_format = "direct"`, output to `/kaggle/working/output_arm_a1/best_adapter`.
  - **Arm A2 (Reasoning Target):** `CFG.train_target_format = "reasoning"`, output to `/kaggle/working/output_arm_a2/best_adapter`.

### Step 4: NB3 Evaluation (`nb3_infer.ipynb`)
- **Settings:** **GPU T4 × 2**, **Internet ON**.
- Adapter selection is **explicit** (no auto-discovery):
  - Set environment variables:
    ```bash
    export EVAL_ARM="A1"  # or "A2", "A0"
    export ADAPTER_PATH="/kaggle/input/path-to-adapter/best_adapter"
    ```
- Evaluates on synthetic splits and Quiz 3 dev split (23 students).
- Compare Arm A1 vs A2 on `dev` before touching any further pipelines.

### Step 5: (Gated) NB2B NCA Preference Stage (`nb2b_nca.ipynb`)
- Run ONLY if Arm A2 outperforms Arm A1 on dev AND false penalties remain elevated.
- Aligns Arm A2 adapter via Noise Contrastive Alignment (NCA) preference loss.
- Output: `/kaggle/working/output/nca_adapter/best_adapter`.
- Re-evaluate Arm A3 in NB3.
