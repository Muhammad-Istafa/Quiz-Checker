### Step 2: NB1B Local Teacher Distillation (`nb1b_teacher.ipynb` — GPU T4 × 2)
1. Open `notebooks/nb1b_teacher.ipynb`. Settings: **GPU T4 × 2**, **Internet ON**.
2. Loads `Qwen/Qwen2.5-Coder-14B-Instruct` (or `Qwen/Qwen3-14B`) in 4-bit NF4 with `enable_thinking=False`.
3. Runs Ground-Truth Anchored distillation across training records:
   - Validates teacher reasoning, JSON schema, and sandwich feedback.
   - Enforces `abs(teacher_awarded - gold_awarded) == 0`.
   - Fallback to verified code-generated trace if teacher output fails validation.
4. Produces: `/kaggle/working/output/teacher_distilled/train_sft_distilled.jsonl`.
